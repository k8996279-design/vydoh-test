# Выдох

Мини-приложение с карточками, практиками и фоновыми звуками для сна, тревоги и мягкого старта дня.

## Что запускать

- Основной экран приложения: [index.html](/Users/ekaterina/Desktop/выдох/index.html)
- Основные стили: [css/app.css](/Users/ekaterina/Desktop/выдох/css/app.css)
- Основная логика: [js/app/](/Users/ekaterina/Desktop/выдох/js/app/)
- Контент карточек: [js/data/library.js](/Users/ekaterina/Desktop/выдох/js/data/library.js)
- Контент программы `30 дней`: [js/data/program.js](/Users/ekaterina/Desktop/выдох/js/data/program.js)

## Где что редактировать

- Первый экран и поток экранов: `index.html`
- Внешний вид и отступы: `css/app.css`
- Поведение кнопок, переходы, звуки: `js/app/`
- Тексты и карточки практик: `js/data/library.js`
- Данные программы: `js/data/program.js`
- Реальные аудиофайлы: `assets/sounds/`

## Структура

- `index.html` — рабочая версия приложения
- `css/` — стили
- `js/app/` — логика приложения, разбитая по зонам ответственности
- `js/data/` — тексты карточек и программа `30 дней`
- `assets/sounds/` — фоновые звуки
- `concepts/` — старые отдельные варианты обложек
- `archive/` — устаревшие или запасные HTML-версии

## Как работать дальше

- Для точечных визуальных правок обычно достаточно менять `index.html` и `css/app.css`
- Для замены фонового звука можно просто подменить файл в `assets/sounds/` и, если нужно, поправить громкость в `SOUND_LIBRARY` внутри `js/app/sounds.js`
- Отдельные старые макеты вынесены из корня, чтобы не мешали рабочей версии

## Логика по файлам

- `js/app/state.js` — текущее состояние приложения
- `js/app/navigation.js` — переходы между экранами и 30-дневный streak
- `js/app/cards.js` — списки разделов, карточки, избранное в детальном оверлее
- `js/app/mood.js` — быстрый подбор по трём вопросам
- `js/app/home.js` — главный экран и открытие разделов/техник
- `js/app/interactions.js` — интерактивные практики, таймеры, дневник, звуки
- `js/app/program.js` — экран программы `30 дней`, день, ритуалы, модалки
- `js/app/init.js` — стартовые обработчики и первичная инициализация

## PWA и запуск

- Для офлайн-режима и установки на телефон проект нужно открывать не через `file://`, а через локальный или удалённый `http://`/`https://`
- PWA-файлы: `manifest.webmanifest`, `sw.js`, `js/pwa.js`
- Иконки приложения: `assets/app/`

## Быстрый публичный деплой

- Самый быстрый старт сейчас: Netlify Drop или обычный Netlify Free без сборки
- Проект уже готов как статический сайт, поэтому для Netlify не нужен build command
- Папка публикации для Netlify: корень проекта `.` — это уже зафиксировано в `netlify.toml`
- Для первой публикации можно просто перетащить папку проекта в Netlify Drop: [Create deploys | Netlify Docs](https://docs.netlify.com/site-deploys/create-deploys/)
- Для следующего обновления достаточно внести правку локально и заново задеплоить ту же папку или позже подключить Git-репозиторий к Netlify

## Что уже учтено для деплоя

- `netlify.toml` добавлен без перестройки текущей структуры проекта
- Старые публичные пути `archive/*` и `concepts/*` на Netlify будут уводить на главную, чтобы наружу оставалась только актуальная версия
- `sw.js` настроен мягче для обновлений: HTML, CSS, JS и manifest берутся по сети в первую очередь, а кеш используются как запасной вариант
- Это уменьшает риск ситуации, когда правка уже задеплоена, а у пользователя всё ещё открывается старая версия приложения
